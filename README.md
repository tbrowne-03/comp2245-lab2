# comp2245-lab2

This is Lab 2 for Tajhere Browne.

## Project

The goal of the project was to create a one page personal blog built with HTML and an external CSS stylesheet. The layout uses CSS Grid for the page structure, Flexbox for the header, and floats for the images inside the blog posts. 

## Browser Tests
The project works on Google Chrome, Mozilla Firefox, and Microsoft Edge.
